# AI-Pipeline-Demo
// This Hardware AI Pipeline design is a motion detection system that indicates whenever suspicious activity occurs (ex. porch pirates, home invasions) then a fan blade will sound an alert for reconsiderations. The python code is consistent with a TensorFlow that implements a Keras 2 Engine. pyarrow basically is the systems default feature which resists when an import crash occurs in the initiating process of TensorFlow. The OpenCV constitutes as the sensor and indicator of the system, while TensorFlow Keras is trained to load all the data for the python aspect of the model. The Arduino Sketch Code on the contrary, implements the USB serial port conveyed with the Motor Fan Blade product that indicates when the LED blinks, the Fan spins and when the hardware is turned ON, or OFF. The Demo itself is mainly programmed with Python pip installer in which TensorFlow Kera is embedded in, and the Arduino IDE platform, that will operate the output based on the motion detections of the Security Camera System

Aruino Sketch System: 

- Module used is Arduino Mega/Mega 2560 on a COM3 port 
- When initiated, the LED hardware will start blinking when fan is stopped, and the fan spins, when LED stops the blink
- The labels text of Keras features 0 as OFF and 1 as ON, which 2 is BOTH 
- Both is activated when the LED blinks and Fan spins in a synchronized manner, and STOP meaning everything's deactivated. 
- The Arduino Sketch Code will display the pipeline to initiate the LED sequence based on when a movement that's put in effect becomes indicated.
- The Sketch Code also declares both logical operators and programming selection for its label commands 


When the Python Code and it's Keras Label model conveys a signal to the project in Arduino IDE, that means the Security Camera Motion Detection System is in operation and will indicate any suspicious movements that is encountered.  


Assessing the Pipeline 

- Invoke the Arduino IDE derived from the COM3 serial port
- Create the file project on Visual Studio (VS) code with Python installer
- Programming engine is imported with TensorFlow Keras Model
- The Class Objects with Google Teachable Machine become Trained and its models proceed to be exported
- When processing the OS will take photo of Demo Model from the webcam, while both the Motor Fan Blade is spinning and LED light turns ON at the moment when        sudden motions are detected with Security Camera.
